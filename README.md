# Loan PDF Merge Tool — ব্যবহারের নিয়ম

এই টুলটা দিয়ে আপনি **Borrower List PDF** আর **Loan Balance PDF** — এই দুটো ফাইল
আপলোড করে একটা মিলিত (merged) Excel রিপোর্ট বানাতে পারবেন। কোনো কোড লেখা লাগবে না।

এই রিপোতে ৪টা ফাইল আছে:
- `app.py` — Streamlit ওয়েব অ্যাপ (UI)
- `pdf_processor.py` — PDF পার্স করার মূল লজিক
- `requirements.txt` — প্রয়োজনীয় Python লাইব্রেরির তালিকা
- `README.md` — এই নির্দেশিকা

---

## অনলাইন লিংক হিসেবে চালানো (কোনো ইনস্টল ছাড়াই, ব্রাউজার থেকেই কাজ করতে পারবেন)

**খেয়াল রাখবেন:** GitHub নিজে শুধু কোড রাখার জায়গা (স্ট্যাটিক পেজ ছাড়া কোনো Python
কোড রান করতে পারে না)। তাই লিংকে গিয়ে PDF আপলোড করে কাজ করার জন্য GitHub-এর সাথে
**Streamlit Community Cloud** (সম্পূর্ণ ফ্রি) ব্যবহার করতে হবে — GitHub-এ কোড রাখলে
Streamlit Cloud সেটা থেকেই একটা পাবলিক লিংক বানিয়ে দেবে।

### ধাপ ১ — GitHub-এ রিপোজিটরি বানান
1. [github.com](https://github.com)-এ একাউন্ট না থাকলে বানিয়ে নিন (ফ্রি)।
2. উপরে ডানে **+** আইকনে ক্লিক করে **New repository** সিলেক্ট করুন।
3. একটা নাম দিন (যেমন `loan-pdf-merge-tool`), **Public** সিলেক্ট করে **Create repository** চাপুন।
4. তৈরি হওয়া রিপোতে **Add file → Upload files** বাটনে ক্লিক করে এই ৪টা ফাইল
   (`app.py`, `pdf_processor.py`, `requirements.txt`, `README.md`) একসাথে ড্র্যাগ করে
   দিন, তারপর নিচে **Commit changes** চাপুন।

### ধাপ ২ — Streamlit Community Cloud-এ ডিপ্লয় করুন
1. [share.streamlit.io](https://share.streamlit.io)-এ যান এবং **"Sign in with GitHub"** দিয়ে লগইন করুন।
2. **"Create app"** বাটনে ক্লিক করুন।
3. যে রিপোজিটরি বানিয়েছিলেন সেটা সিলেক্ট করুন, Branch: `main`, Main file path: `app.py` দিন।
4. **"Deploy"** চাপুন। ১-২ মিনিট অপেক্ষা করুন — অ্যাপ বিল্ড হবে।
5. বিল্ড শেষ হলে একটা লিংক পাবেন (যেমন `https://your-app-name.streamlit.app`) —
   এই লিংক যে কেউ ব্রাউজারে খুলে PDF আপলোড করে কাজ করতে পারবে, কোনো ইনস্টল ছাড়াই।

**পরে কোড আপডেট করলে:** GitHub রিপোতে ফাইল বদলে/আপলোড করে commit করলেই Streamlit Cloud
স্বয়ংক্রিয়ভাবে নতুন ভার্সন দিয়ে অ্যাপ রিফ্রেশ করে দেবে — নতুন করে ডিপ্লয় করা লাগবে না।

## নিজের কম্পিউটারে চালানো (Local)

### ১. একবারের জন্য প্রস্তুতি (Setup)

#### ১.১ Python ইনস্টল করুন
- [python.org/downloads](https://www.python.org/downloads/) থেকে Python ডাউনলোড করে ইনস্টল করুন।
- **Windows-এ ইনস্টল করার সময় অবশ্যই "Add Python to PATH" বক্সে টিক দেবেন।**

#### ১.২ এই ফোল্ডারটা কোথাও রাখুন
`app.py`, `pdf_processor.py`, `requirements.txt` — এই তিনটা ফাইল একই ফোল্ডারে রাখুন
(যেমন: `Desktop\LoanMergeTool\`)।

#### ১.৩ প্রয়োজনীয় লাইব্রেরি ইনস্টল করুন
- **Windows:** Start মেনুতে গিয়ে `cmd` লিখে Command Prompt খুলুন।
- ফোল্ডারে যান, যেমন:
  ```
  cd Desktop\LoanMergeTool
  ```
- তারপর লিখুন:
  ```
  pip install -r requirements.txt
  ```
- কিছুক্ষণ অপেক্ষা করুন, ইনস্টল শেষ হলে পরের ধাপে যান।

### ২. প্রতিবার অ্যাপ চালানোর নিয়ম

একই Command Prompt-এ (বা নতুন একটা খুলে ফোল্ডারে গিয়ে) লিখুন:

```
streamlit run app.py
```

- একটা ব্রাউজার উইন্ডো নিজে থেকেই খুলে যাবে (যদি না খোলে, টার্মিনালে দেখানো
  `http://localhost:8501` লিংকে গিয়ে ব্রাউজারে পেস্ট করুন)।
- অ্যাপ বন্ধ করতে চাইলে টার্মিনালে `Ctrl + C` চাপুন।

## অ্যাপে কীভাবে কাজ করবেন (অনলাইন বা লোকাল — একই নিয়ম)

1. **ধাপ ১:** দুটো বক্সে দুটো PDF আপলোড করুন — Borrower List ও Loan Balance।
2. **ধাপ ২:** "🔍 PDF স্ক্যান করুন" বাটনে চাপুন। কয়েক সেকেন্ড পর একটা তালিকা আসবে —
   প্রতিটা Loan Program-এর জন্য একটা Prefix (যেমন "Own", "JR") স্বয়ংক্রিয়ভাবে বসানো
   থাকবে। চাইলে Prefix কলামে ক্লিক করে নিজের মতো বদলে দিতে পারেন।
3. **ধাপ ৩:** "✅ Merge করে Excel তৈরি করুন" বাটনে চাপুন।
4. "⬇️ Excel ফাইল ডাউনলোড করুন" বাটনে চাপে ফাইলটা নিজের কম্পিউটারে নামিয়ে নিন।

## "⚠ যাচাই দরকার" ফ্ল্যাগ মানে কী?

খুব কম সংখ্যক রো-তে (সাধারণত ৫%-এর কম) PDF-এ নাম দুই লাইনে ভাগ হয়ে ছাপা হওয়ায়
Father/Spouse/Village আলাদা করা কঠিন হয়ে পড়ে। এই টুল ভুল অনুমান করে ডেটা না বসিয়ে
সেই রো-গুলো Excel-এ **হলুদ রঙে** চিহ্নিত করে এবং "নোট" কলামে কারণ লিখে দেয় —
যাতে আপনি একবার চোখ বুলিয়ে হাতে ঠিক করে নিতে পারেন। বাকি সব রো স্বয়ংক্রিয়ভাবে
নির্ভুলভাবে পূরণ হয়।
